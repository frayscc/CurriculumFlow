# 月历时间轴与同步约束

## 三阶段调整

1. 数据同步：记录本机同步基线；服务器与本机同时修改时停止上传，不再用旧快照覆盖服务器。刷新页面保留待同步修改。读取服务器前保存独立的本机恢复副本。
2. 时间轴模型：以任务的 `scheduledDates` 为实际占用日期来源，统一生成最终版课表。插入、移动、缩放、删除、修改校历和学期均通过事务更新，剩余教学日不足则整体回滚。
3. 交互与回归：统一拖放操作类型；拖放或选日期时避免课程横条遮挡目标日；提供点击选日期的插入、缩放方式；修复无安排时导出页一直加载的问题。

## 时间轴行为

- 每个上课日最多占用一项教学内容；节假日、考试状态日不能接收教学内容。
- 在某日插入新内容，从该日开始占用，其后的安排按照插入长度顺延，之前的安排保持不变。
- 在长课程内部插入内容，保留其已排前段，后段顺延。原课程可因此分成多个显示片段，仍属于同一个任务。
- 移动已排课程先关闭原位置占用的空缺，再从目标日重新插入；目标日是精确锚点，不自动跳到其他课程起点。
- 延长课程在末段追加教学日，后续安排顺延；缩短或移回待安排区关闭相应空缺。
- 拖动手柄时实时预览跨度和后续安排，横条以短过渡变长、变短；提示目标结束日及占用教学日数。预览与保存共用缩放规则，只在松手时写入；非法目标、拖出月历、Escape 或失焦时恢复原安排。缩短移除原手柄片段时，稳定月历网格仍保持指针捕获。系统开启减少动态效果时禁用动画，保留即时预览。
- 拖动课程横条中心可移动整门课程，保持教学日数和抓取位置；拖动右侧手柄仍只调整跨度。中心点击后也可选择新的开始日期，非法日期和取消操作同样不会写入预览状态。
- 跨周、跨月、遇到非教学日时，横条分段显示；占用的教学日期仍通过同一任务关联。
- 新增“考试”教学内容与将校历日期设为“考试”不同：前者参与时间轴插入，后者将当天从可用教学日中移除。
- 课程日数由占用日期决定，编辑名称、类型不会重置已经安排的跨度。
- 历史项目复制只复制内容，不沿用旧日期。旧版安排优先用已保存的课表迁移，以保留原跨度。

## 冲突副本

恢复副本仅保存在当前浏览器，不上传服务器。下载后的 ZIP 中，`projects/` 内的项目 ZIP 可在“完整备份”页面逐个恢复；`workspace.json` 和 `files/` 保存原始数据。发生冲突时不自动合并两份工作空间。

## 验证范围

执行 `npm test`、`npm run lint`、`npm run build`。测试覆盖同步冲突、重开页面待同步修改、并发初始化、恢复副本、时间轴插入/缩放/删除、校历重排、容量不足回滚、历史复制、拖放事件以及导出空状态。

右侧手柄使用指针事件调整跨度，不依赖原生 HTML 拖放。真实浏览器已验证点击插入、点击手柄选择结束日期、鼠标拖动右侧手柄及跨周延长后的后续顺延。跨月选日期、非法日期拒绝、拖出月历取消、按 Escape 取消等通过交互测试覆盖。课程卡片插入仍使用 HTML 拖放，同时提供点击后选插入日期的方式。

V1.5.4 修复点击手柄后自身被禁用的问题。缩放使用指针捕获和日期格几何位置判断结束日，禁止原生拖动浮影；横条处于统一高度，并保持在相邻日期的选中背景之上。已在真实浏览器验证“先点击手柄，再拖到次日”及选中次日时的完整跨日显示。
